## Quy tắc ngừa tái phạm (áp dụng từ track này)

1. Tiêu chí xong phải phủ **đầy đủ đường user**: UI → socket → sidecar → engine → UI. Engine-level không tính là xong nếu UI gọi được nhưng app cài không chạy được.
2. Mỗi lần bump version: chạy `check-version-sync` (H1.2) — không kiểm bằng mắt.
3. Mỗi lần build installer: pre-build check (H1.3) + smoke (H3) bắt buộc trước khi gọi là "build xong".
